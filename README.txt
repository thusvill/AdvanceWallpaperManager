Advance Wallpaper Manager — static GitHub Pages site

Files:
- index.html
- style.css
- script.js

Deploy:
1. Put these files in the root of your GitHub Pages branch/folder.
2. Enable GitHub Pages for that source.
3. No build step is required.

GitHub integration:
- Repository stats, releases, assets, and contributors load from the public GitHub REST API.
- The hero Download APK button automatically targets the newest published APK when one exists.
- Release notes support the common Markdown constructs used in GitHub releases.

Customization:
- Replace the CSS placeholder artwork in the hero/editor/gallery with your own screenshots or image assets.
- Update links/text in index.html as your distribution changes.

Icons:
- Icons are loaded from the Icons8 CDN in monochrome form.
- Keep the "Icons by Icons8" attribution link in the footer when using these assets; see https://icons8.com/license

Theme:
- Light/dark mode is controlled with the theme toggle and saved in localStorage.
- Colors use shared Material-style CSS custom properties for both schemes.
